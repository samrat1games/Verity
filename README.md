# Verity — Android

Нативный Android-питомец и клиент для общения через OpenAI-compatible API.

## Что уже работает

- Material You и динамические цвета Android 12+
- 51 готовый пресет провайдеров, включая Google Gemini, и полностью настраиваемый Custom API
- выбор Base URL, модели и API-ключа
- локальное сохранение, открытие и удаление чатов
- летающий Verity поверх других приложений: его можно бросать, он отскакивает от краёв
- распознавание речи по короткому нажатию на экранного Verity
- текстовые реплики рядом с питомцем, разбитые на страницы кнопкой «Ещё»
- самостоятельное движение по экрану, инерция, отскоки и реакция на столкновения
- первое знакомство с посылкой и текстовым запросом разрешений
- компактная память предыдущих разговоров даже после создания нового чата
- локальные серверы Ollama, LM Studio, LocalAI, Jan, vLLM и LiteLLM

## Запуск

1. Откройте папку проекта в Android Studio.
2. Запустите конфигурацию `app` на Android 8.0 или новее.
3. В меню Verity откройте **Настройки**, выберите провайдера, укажите API-ключ и модель.

Для сборки из терминала:

```shell
./gradlew assembleDebug
```

Готовый debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Готовую сборку также можно скачать с сайта проекта или из файла [`Verity.apk`](Verity.apk) в корне репозитория.

Некоторые облачные пресеты требуют заменить заглушку в Base URL (`ACCOUNT_ID`, `RESOURCE`, `DEPLOYMENT`, `ENDPOINT` или `MODEL`). Все URL и модели можно изменить прямо в приложении.

## Приватность

История, настройки и API-ключ хранятся локально в данных приложения. Сообщения отправляются только на выбранный пользователем Base URL. API-ключи не включены в исходный код.
